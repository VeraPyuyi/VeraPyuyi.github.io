# Paper web fonts

These fonts are served locally so the HTML versions of the papers follow the typefaces selected in their TeX sources.

- `latin-modern-*.woff2`: Latin Modern text faces distributed with LaTeX.css; the font files are covered by the GUST Font License and the packaging project by MIT. The bundled MIT notice is in `licenses/latex-css-MIT.txt`.
- `latin-modern-math.woff2`: Latin Modern Math 1.959, converted to WOFF2 by the MathFonts project without changing the reserved font name. It is covered by the GUST Font License in `licenses/latin-modern-GUST.txt`.
- `computer-modern-*.woff2`: Computer Modern Unicode serif faces, covered by SIL Open Font License 1.1 in `licenses/computer-modern-OFL.txt`.
- `computer-modern-math.woff2`: New Computer Modern Math Book 7.1, the OpenType MATH companion used for the Computer Modern paper profile. It is converted to WOFF2 by the MathFonts project and covered by the GUST Font License in `licenses/latin-modern-GUST.txt`.

The website source license does not replace these font licenses.
